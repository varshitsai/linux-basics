# Day 2 – Linux Filesystem & Permissions

## What I learned
- Linux filesystem structure (/home, /etc, /var)
- Difference between root and normal user
- Why /var/log needs sudo access
- Using sudo to access protected directories

## Commands practiced
ls /
ls /home
ls /var
sudo ls /var/log

## Key takeaway
Permission denied is a security feature, not an error.
